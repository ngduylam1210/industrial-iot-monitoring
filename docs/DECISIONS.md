# Architecture & Engineering Decisions

Status: Draft

## ADR-001 — Project Direction

Decision:
Focus the project on Embedded Systems, Industrial IoT, and Automation.

Reason:
Align the project with the target career direction.

## ADR-002 — Main Controller

Decision:
STM32 is the main embedded controller.

Reason:
Use STM32 to demonstrate embedded programming,
real-time processing, and FreeRTOS.

## ADR-003 — IoT Gateway

Decision:
ESP32 is used as the IoT Gateway.

Reason:
Use ESP32 for Wi-Fi, networking, and MQTT communication.

## ADR-004 — Industrial Communication

Decision:
Use RS485 with Modbus RTU.

Reason:
Demonstrate industrial communication skills.

## ADR-005 — Project Strategy

Decision:
Build one integrated flagship project instead of multiple
independent projects.

Reason:
Maximize the value of limited time and budget.
