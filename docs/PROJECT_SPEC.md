# Project Specification

## Project Title
Industrial IoT Monitoring & Predictive Maintenance System

## Objective
Build a prototype Industrial IoT system for monitoring
industrial equipment and detecting abnormal operating conditions.

## Career Direction
- Embedded Systems
- Industrial IoT
- Automation

## Main Controller
STM32

## IoT Gateway
ESP32

## Industrial Communication
RS485 / Modbus RTU

## IoT Communication
MQTT

## Backend
Python-based backend

## Machine Learning
Anomaly detection

## Main Monitoring Targets
- Motor speed
- Motor current
- Temperature
- Other relevant equipment parameters

## Budget
Approximately 1.5–2 million VND for additional hardware.

## Existing Hardware
- STM32
- ESP32

## Project Scope
The system should demonstrate:
- Embedded real-time data acquisition
- Sensor processing
- Motor/equipment monitoring
- Industrial communication
- IoT gateway
- Cloud/backend communication
- Data visualization
- Basic anomaly detection
- Fault/alarm handling

## Constraints
- Reuse existing hardware whenever possible.
- Avoid unnecessary hardware purchases.
- Prioritize skills relevant to Embedded, Industrial IoT, and Automation.
- Build and test the system incrementally.
